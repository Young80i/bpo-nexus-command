# BPO Nexus Project Context

## Project Overview

**Project Name**: BPO Nexus Command
**Purpose**: AI-powered project management system for software outsourcing company
**Repository**: https://github.com/Mancoba/bpo-nexus-command

## System Architecture

### Frontend
- **Framework**: React with TanStack Start (file-based routing)
- **Styling**: Tailwind CSS with custom design system
- **Components**: Modular UI component library
- **State Management**: React Context patterns with custom stores
- **Type Safety**: Full TypeScript implementation

### Backend Integration
- **Data Management**: Client-side stores with persistence
- **API Integration**: Custom gateway patterns
- **AI Integration**: Lovable and Continue workflow support

### Key Systems
1. **JEMS (JARVIS Engineering Management System)**: Governance framework
2. **Repository Intelligence Engine**: Codebase analysis system
3. **Architecture Intelligence Engine**: Quality assessment system
4. **Engineering Delivery Pipeline**: Complete workflow management
